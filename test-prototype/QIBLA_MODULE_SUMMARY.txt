PROJECT OVERVIEW
================================================================================
A production-ready HTML/CSS/JavaScript testing interface for the Qibla 
direction calculation API. Features interactive coordinate input, browser 
geolocation, animated visual compass, and comprehensive error handling.

JAVASCRIPT CLASS: QiblaTester
================================================================================
Methods:
  • init()                          - Initialize module and DOM
  • calculateQibla(lat, lng)        - Call API and display results
  • useCurrentLocation()            - Browser geolocation integration
  • displayQibla(data)              - Show results from API
  • drawCompass(direction)          - Render compass on canvas
  • animateCompassNeedle(direction) - Smooth rotation animation
  • validateCoordinates(lat, lng)   - Input validation
  • showError(message)              - Error display
  • showLoading(isLoading)          - Loading state
  • reset()                         - Reset to initial state

USAGE
================================================================================
Quick Start:
  1. Open qibla-test.html in browser
  2. Enter coordinates or click "Use My Location"
  3. Click "Calculate Qibla"
  4. View results and compass animation

Command Line Test:
  node test-qibla-api.js

Local Server (for geolocation):
  python3 -m http.server 8080
  # Open: http://localhost:8080/qibla-test.html
