## 🚀 Quick Start for Unity Team

### Step 1: Install Supabase Unity SDK
```
Window → Package Manager → Add package from git URL
https://github.com/supabase-community/supabase-unity.git
```

### Step 2: Read the Integration Guide
👉 https://github.com/Amineregayeg/umrah-hajj-realtime/blob/deploy/koyeb-setup/UNITY_AUTH_INTEGRATION_GUIDE.md

### Step 3: Copy the C# Scripts
The guide contains ready-to-use scripts:
- `SupabaseManager.cs` - Supabase client setup
- `AuthManager.cs` - Login/Registration
- `BackendAPIManager.cs` - API calls with JWT
- `NavigationWebSocketManager.cs` - Real-time navigation

### Step 4: Configure with Credentials
Use the Supabase URL and Anon Key from above.

### Step 5: Test
Create test user, login, and call backend APIs!
